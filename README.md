# Escandinavo RPG

Mesa virtual para RPG de mesa (virtual tabletop).

## Sobre

Projeto renomeado de **Manipulação** para **Escandinavo**.

Permite:
- Upload de mapas
- Criação e manipulação de tokens
- Grid, zoom, fog of war (em desenvolvimento)
- Salvamento local (localStorage)
- Biblioteca de tokens
- Undo/Redo, copiar/colar

## Como usar

1. Abra o `index.html` em um navegador moderno
2. Ou sirva a pasta com um servidor local (ex: `npx serve .`)

## Estrutura

- `index.html` – interface principal
- `main.js` – núcleo da aplicação
- `tokens.js` – sistema de tokens
- `library.js` – biblioteca de tokens
- `storage.js` – persistência
- `drag.js` – arrastar tokens e pan do mapa
- `grid.js` – sistema de grid
- `zoom.js` – controle de zoom
- `ui.js` – eventos da interface
- `contextMenu.js` – menu de contexto
